# C# gameplay code examples

These are **selected first-party scripts** from the private Ashveil Relics Unity project:

- [PlayerDodge.cs](PlayerDodge.cs): directional dodge and physics collision checks.
- [SkeletonBrain.cs](SkeletonBrain.cs): common enemy AI, attack feedback and encounters.
- [LuciferBoss.cs](LuciferBoss.cs): boss state machine, attack handling and phases.

The scripts are intended for **code review**, not standalone compilation. Other Unity scripts, scenes, prefabs, animator controllers, textures and sound files are not included.

To play the working game, download the Windows demo from [itch.io](https://arojases.itch.io/ashveil-relics). The complete Unity repository remains private to protect third-party art.
