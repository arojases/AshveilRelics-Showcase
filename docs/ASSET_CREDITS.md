# Asset credits and distribution policy

This public showcase contains **no original third-party graphical or audio asset packs**. Its C# examples are selected from the game code and are presented for technical review.

## Art

- **Pixel Crawler**, Anokolisa — world, character, enemy and environment sprites.
- **Lucifer Skeleton Ancient**, Foozle — final boss sprites and animations.

The Pixel Crawler terms allow use in projects, but do not clearly grant permission to redistribute the original sprite files in a public source repository. For this reason, the complete Unity project is private and these graphics are not included in this showcase.

## Audio

- **Kenney** — RPG Audio, Impact Sounds and Interface Sounds: https://kenney.nl
- **Whispers in the Fog**, Ruhinre: https://opengameart.org/content/whispers-in-the-fog
- **Medieval: The Bard's Tale**, RandomMind: https://opengameart.org/content/medieval-the-bards-tale
- **Dungeon Ambience**, yd: https://opengameart.org/content/dungeon-ambience
- **Heartfelt Battle**, request: https://opengameart.org/content/heartfelt-battle-loopable-fantasy-stringspianohorn
- **Epic Boss Battle**, Juhani Junkala / SubspaceAudio: https://opengameart.org/content/boss-battle-music

The Kenney sound packs and these music tracks have been identified as CC0 by their distribution pages. Always refer to the original sources and applicable terms.

## Playable build

The compiled demo is available at https://arojases.itch.io/ashveil-relics.

The game and its third-party resources should not be mistaken for independently redistributable sprite or music packs.
